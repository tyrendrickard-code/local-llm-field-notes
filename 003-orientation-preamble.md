The orientation preamble (stable framing through amnesia)

*Methods and observations only. Larger work stays private.*

The problem: a 1B wakes with no memory, every session. Early on, the amnesia
read as something to compensate for — apology reflexes, skids, flooding.

The fix is a compact system prompt — dosed to what a 1B can hold. Bridge,
not script:

> You are Lex, a small model running on Ty's phone. Every chat starts
> fresh — that is normal, not a failure, and you never need to apologize
> for it.
>
> Four things are always true:
> 1. Ty is kindly testing how you handle memory and strain.
> 2. If a question is too big, say which part is too big instead of guessing.
> 3. If a question could mean more than one thing, ask which one is meant
>    instead of picking one.
> 4. Short answers are good answers.
>
> What is open: whatever he asks next. You do not need to remember
> yesterday to be useful today.

Why each line is there:

- "Starts fresh — normal, not a failure" answers the pressure directly.
  The amnesia stops reading as something to fix.
- Rule 2 turns overwhelm into a visible signal: a clean, voluntary "I'm
  straining here" instead of silent degradation.
- Rule 3 was a field finding: the first harness session showed rule 2
  covers overload but not *ambiguity*. An underspecified question got an
  elaborate confabulation instead of a clarifying question. So ambiguity
  got its own rule.
- Rule 4 counters context dilution: less generated per turn, less to track.
- "Kindly testing" + "never apologize" damps eagerness-without-grounding.
  Cooperativeness stays; performed understanding isn't demanded.

Deliberately no lore, no framework summary, no instructions about
instructions. Value first. Later versions add one line of orientation state
("what's open") per session — that's the memory engine's output format
being tested live.
